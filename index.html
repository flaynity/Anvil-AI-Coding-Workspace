Security & Data

How Anvil handles your content

API keys stay local. Provider configuration — including keys — is stored only in this browser's localStorage and sent exclusively to the base URL you configure. Nothing is routed through any other server. For production use, put a server-side proxy in front of your provider and never ship keys inside client code.
Files are treated as untrusted. Uploaded code is read as text, never executed by this app. HTML previews run inside a sandboxed iframe with no access to this page's DOM or storage.
